Hacker Bloc ASCII art collection

Add a design by writing === Your design name === on its own line,
then paste the artwork underneath. Keep its spaces and line breaks intact.
Use a different name for each design. Do not wrap the art in quotes or code fences.

The first design is shown on the homepage. Move a different design to the top
to try it, then save this file and refresh the page.
Artwork is monochrome by default; ANSI color codes are removed automatically.
Add @color: apple directly below a design's heading for classic rainbow stripes.
Empty sections are ignored, so you can leave names here to fill in later.
After deployment, changes to this file need a new deployment.
